# 毕业设计：基于Spring Boot + Vue的个人博客系统设计与实现

## 1. 系统功能结构

本系统采用B/S架构，分为前台门户（面向访客）和后台管理（面向管理员）两个部分。

### 1.1 前台门户
*   **首页模块**：展示轮播图、文章列表、个人侧边栏信息。
*   **文章浏览**：支持Markdown渲染、代码高亮、目录导航、点赞、评论。
*   **归档分类**：支持按时间轴归档、按分类和标签筛选文章。
*   **关于博主**：展示个人简介、技术栈、项目说明。
*   **全站搜索**：支持关键词搜索文章。

### 1.2 后台管理
*   **仪表盘**：展示文章数、访问量、评论数等统计数据。
*   **内容管理**：
    *   文章管理：发布、编辑、删除、草稿箱。
    *   分类管理：文章分类的增删改查。
    *   标签管理：文章标签的增删改查。
*   **用户管理**：管理员信息修改、密码重置。
*   **系统设置**：网站基本信息配置（标题、Logo、备案号等）。

## 2. 技术选型理由

### 2.1 后端：Spring Boot + MyBatis Plus
*   **Spring Boot (2.7)**：作为Java生态最主流的框架，提供了自动配置和快速开发能力，适合毕设周期的快速迭代。
*   **MyBatis Plus**：在MyBatis基础上进行了增强，提供了强大的CRUD接口，极大地减少了SQL编写量，提高了开发效率。
*   **Sa-Token**：相比Spring Security更加轻量级，上手简单，非常适合个人博客这种中小型的权限管理需求。

### 2.2 前端：Vue 2 + Vue 3
*   **前台 (Vue 2)**：采用Vue 2 + Element UI，生态成熟，组件丰富，保障了前台页面的兼容性和稳定性。
*   **后台 (Vue 3)**：采用Vue 3 + TypeScript + Element Plus + Vite，展示了对前端最新技术的掌握，提升了后台管理的交互体验和开发效率。

### 2.3 数据存储
*   **MySQL (8.0)**：成熟稳定的关系型数据库，用于存储核心业务数据。
*   **Redis**：用于缓存热点数据（如文章阅读量、配置信息）和用户Session，提升系统响应速度。

## 3. 数据库设计

核心数据表设计如下：

| 表名 | 中文名 | 关键字段 | 作用 |
| :--- | :--- | :--- | :--- |
| `sys_user` | 用户表 | `username`, `password`, `avatar` | 存储管理员及用户信息 |
| `sys_article` | 文章表 | `title`, `content`, `category_id`, `read_type` | 存储文章内容及元数据 |
| `sys_category` | 分类表 | `name`, `icon` | 文章分类管理 |
| `sys_tag` | 标签表 | `name`, `color` | 文章标签管理 |
| `sys_comment` | 评论表 | `article_id`, `content`, `user_id` | 存储用户评论互动 |
| `sys_web_config` | 网站配置 | `title`, `logo`, `author_info` | 存储网站全局配置 |

## 4. 核心功能实现思路

### 4.1 文章管理
采用Markdown编辑器（MavonEditor/WangEditor）实现所见即所得的编辑体验。文章发布时，通过事务同时更新`sys_article`表和`sys_article_tag`关联表。前台展示时，使用`markdown-it`或类似库将Markdown转换为HTML，并配合`highlight.js`实现代码高亮。

### 4.2 权限控制
基于RBAC（Role-Based Access Control）模型简化版。使用Sa-Token进行登录认证（StpUtil.login），登录后生成Token存储在Redis中。后台接口通过注解（如`@SaCheckLogin`）进行拦截验证，确保只有管理员才能进行增删改操作。

## 5. 改进与创新点（毕设亮点）

本项目在原开源项目基础上，进行了深度的二次开发和重构，主要体现在以下方面：

### 5.1 界面视觉重构 (UI/UX Upgrade)
*   **配色方案**：抛弃了原有的通用配色，采用了更具学术气息和科技感的**深蓝 (#1a3b5d) + 浅灰 (#f8f9fa)** 配色体系，配合 **橙色 (#e67e22)** 作为强调色，视觉体验更加舒适专业。
*   **字体优化**：引入了 **霞鹜文楷 (LXGW WenKai)** 开源字体，极大地提升了中文博客的阅读体验，兼具宋体的优雅和楷体的书写感。
*   **卡片式布局**：全面重构了首页和文章页布局，增加了圆角、阴影和微交互动画，使页面更具层次感和现代感。

### 5.2 功能精简与聚焦 (Feature Streamlining)
*   **轻量化改造**：移除了对于个人博客冗余的模块（如多租户、复杂的部门管理、代码生成器、监控中心等），使系统更加轻便，启动速度更快。
*   **纯净登录**：移除了复杂的第三方登录（QQ/微信/GitHub），回归最纯粹的账号密码登录，减少了外部依赖，更适合作为独立的毕业设计演示。

### 5.3 沉浸式阅读体验 (Immersive Reading)
*   **排版优化**：针对文章详情页进行了专门的排版优化，调整了正文宽度（限制在 900px 以内）、行高（1.8-2.0）和字间距，缓解长时间阅读的视觉疲劳。
*   **代码阅读优化**：定制了代码块样式，增加了仿MacOS的窗口按钮和一键复制功能，提升了技术类文章的阅读效率。

### 5.4 智能化集成 (AI Integration)
*   **AI摘要**：在文章头部集成了AI摘要展示区（前端实现），模拟了现代博客智能总结文章核心内容的功能，增加了系统的科技感。
