毕业设计（论文）开题报告
一、本课题的目的及意义
（一）本课题的目的
本课题的目的是开发一个基于SpringBoot+Vue的个人博客系统，为个人用户提供一个简洁高效、功能全面、定制化强的博客创作与管理平台。系统采用Java编程语言作为后端开发语言，以MySQL作为结构化数据存储数据库，整合MyBatis实现数据持久化，前端基于Vue框架结合ElementUI组件库构建。主要实现以下功能模块：用户管理模块、博客内容管理模块、互动模块、数据统计模块、后台管理模块等核心功能模块，涵盖用户注册登录、文章发布编辑、分类标签管理、评论点赞互动、数据可视化统计及系统后台审核管理等全流程功能。
（二）本课题的意义
个人博客是用户展示自我、分享知识与交流思想的重要线上载体。当前常见的博客平台往往存在两方面问题：要么功能冗余、操作复杂、可定制性低；要么过于简单，缺乏良好的互动功能与性能优化，难以兼顾简洁易用与功能完整，影响使用体验。因此，本课题拟开发一个基于SpringBoot的个人博客系统，采用SpringBoot+Vue前后端分离架构，以提升系统稳定性与响应速度；选用MySQL数据库，保障数据的安全存储与高效访问。本课题也是对软件工程专业知识的综合实践，有助于深入掌握B/S架构、前后端分离、数据库设计及系统安全等核心技能。
二、国内外研究现状分析
一、国外研究现状
国外个人博客系统发展起步早，已形成成熟多元的产品格局。以WordPress和Medium为代表，分别奠定了开源可定制与商业化体验两种主要路径。WordPress凭借其强大的PHP插件生态，能够支持从个人到企业级的复杂需求，但其功能冗余对普通用户构成了使用门槛；Medium则通过卓越的排版和内置的读者网络，提供了优质的写作与阅读环境，但其平台中心化的内容归属模式与付费墙机制也限制了创作者的自主权。
技术演进呈现出明显的轻量化与现代化趋势。为应对传统平台的臃肿问题，以Node.js驱动的Ghost聚焦于极简的写作体验，而基于Rust的静态站点生成器Zola等新兴工具，则以其高性能和单一二进制文件的简洁部署，吸引了追求效率与可控性的开发者。同时，AI辅助写作、区块链存证等前沿技术的探索性应用，也持续推动着系统智能化与安全性的发展。
在用户体验层面，响应式设计、暗黑模式与无障碍访问等功能已成为行业标配，体现了对细节的深度关注。然而，这些系统在面向中文市场时，普遍存在语言本地化支持不足、国内访问延迟高以及部分海外服务依赖带来的合规风险等明显短板，这在一定程度上限制了其在中文用户中的广泛普及，也为本土化系统的创新留下了明确空间。
二、国内研究现状
国内个人博客系统发展聚焦本土化需求与技术适配，形成 “平台型社区 + 轻量化开源框架” 双轨并行的格局。平台层面，CSDN、博客园等技术社区凭借流量扶持与垂直领域聚集效应，成为技术从业者的核心选择，但存在广告推送过多、自定义权限受限等问题；知乎专栏、简书则强化图文混排与社交互动功能，契合国内用户内容分享习惯。
技术应用方面，国内系统正逐步从传统 PHP 架构向前后端分离转型。开源框架中，基于 Node.js 的 Hexo 因快速部署特性受到青睐，但需本地生成静态文件，不适合频繁更新场景；Typecho 作为轻量级 PHP 系统插件丰富，却因 2018 年后未更新版本，存在安全漏洞风险。近年来，SpringBoot+Vue 技术栈凭借高效开发、性能稳定的优势，成为国内个人博客系统开发的主流选择，通过整合 Redis 缓存、MySQL 数据库、Elasticsearch 全文检索等组件，实现了内容管理、互动交流等核心功能的优化升级。
当前国内研究仍存在明显瓶颈：一是技术同质化严重，多数系统功能集中于文章发布、评论互动，缺乏 AI 推荐、数据可视化等创新功能；二是部分开源项目维护滞后，安全防护能力不足，SQL 注入、XSS 攻击等漏洞频发；三是平台生态封闭，内容导出格式受限，用户迁移成本高，且移动端适配体验参差不齐，难以满足现代用户的个性化与高效化需求。
三、本课题研究的主要内容
本课题以开发一款易用性强、扩展性好、性能稳定的基于SpringBoot的个人博客系统为核心目标，研究内容围绕读者、游客、博主、网站管理员四大角色的功能模块开发展开，具体如下：
一、游客角色功能
1.博客浏览：支持按时间、分类、标签筛选浏览博客列表，可直接查看公开博客全文。
2.内容搜索：通过标题、关键词检索目标博客，快速获取所需信息。
3.分类标签查看：浏览系统全部博客分类及标签，点击即可查看对应分类下的博客内容。
二、读者角色功能
1.账户管理：支持注册登录，可编辑昵称、头像等个人信息，具备密码修改功能。
2.互动操作：可对博客进行评论、点赞及回复他人评论，查看个人评论记录与回复通知。
3.收藏与记录：收藏感兴趣的博客并管理收藏列表，查看历史浏览记录。
三、博主角色功能
1.账户管理：支持注册登录，可编辑个人资料（昵称、简介、头像等），具备密码修改、账户安全设置功能。
2.博客管理：实现博客发布、编辑、删除、草稿保存，支持文本编辑及分类、标签关联；查看单篇博客的阅读量、点赞数、评论数。
3.互动管理：查看并回复、删除读者评论，接收评论、点赞相关系统通知。
4.数据查看：在个人中心查看博客总发布量、总阅读量、总点赞数、总评论数等统计数据。
四、网站管理员角色功能
1.用户管理：查询、禁用读者和博主账号，支持重置用户密码。
2.文章管理：查看、编辑、删除违规博客文章，推荐优质博客至首页。
3.分类标签管理：创建、编辑、删除系统级博客分类。
4.评论管理：查看、删除违规评论。
四、拟采用的研究思路（方法、技术路线、可行性论证等）
（一）研究方法
1. 文献研究法：通过中国知网、GitHub 等平台，检索 Spring Boot、Vue 框架应用及个人博客系统开发相关的文献与开源案例，梳理主流技术栈和核心功能设计方案，为系统开发提供理论参考。
2. 需求分析法：通过线上检索相关文献调研读者、博主等目标用户的需求，明确系统需实现的核心功能。
3. 迭代开发法：分三个周期推进开发：第一周期完成基础架构搭建与注册登录、博客浏览等核心功能；第二周期开发评论互动、分类标签管理等拓展功能，修复已知问题；第三周期优化系统性能，完善细节功能。
4. 系统测试法：采用黑盒测试验证功能是否达标，确保系统稳定可用。
（二）技术路线
1. 需求分析与规划：明确用户需求，划分功能模块，制定开发计划
2. 架构设计与技术选型：后端采用 Spring Boot 框架，搭配 MyBatis 实现数据操作、MySQL 存储数据；前端使用 Vue 框架结合 ElementUI 组件库构建页面；
3. 核心模块开发：后端按角色开发对应功能，包括用户账户管理、博客创作与管理、评论互动、后台审核等；前端实现首页、详情页、个人中心等界面，完成前后端数据对接。
4. 系统测试与优化：修复功能漏洞，优化页面加载速度，确保系统操作流畅。
（三）可行性论证
1. 技术可行性：Spring Boot、Vue、MySQL 均为成熟易用的技术，相关教程和案例丰富，本人本科阶段已学习 Java、Web 开发及数据库相关课程，具备基础开发能力，指导教师可提供技术支持，能解决开发中的常见问题。
2. 资源可行性：个人笔记本电脑可满足开发环境需求，阿里云学生服务器用于部署测试；开发工具（IntelliJ IDEA、VS Code）。
3. 时间可行性：按阶段分配开发、测试、部署时间，进度安排合理，在规定时间内完成任务。
4. 市场可行性：现有部分博客平台功能复杂或定制化不足，本系统聚焦核心需求，操作简洁、功能实用，可满足普通创作者和读者的使用需求，具有实际应用价值。
五、研究工作安排及进度
工作安排：首先确定数据库表，理清表与表之间的关系，然后进行相应的框架搭建，要明确本课题实现所有的功能，对于不熟悉或者没掌握的技术功能，通过查询资料来实现。系统初步搭建好之后进行代码的编写，代码编写完成后按照划分的模块逐一进行模块的测试与功能的完善。最后测试编写好的系统并进行相应的完善，确保系统实现全部的功能并且不存在漏洞
